# Docs

Project specs live at the repository root (`CLAUDE.md`, `AGENTS.md`,
`ARCHITECTURE.md`, `DATABASE.md`, `DESIGN.md`, `SEO.md`, `SKILL.md`).
This folder holds everything else.

| Folder | What it holds |
|---|---|
| `deployment/` | Runbooks still in use: staging/production `.env` templates, the production cutover checklist and the rollback procedure. The deploy scripts in `scripts/` link here. |
| `reports/` | Point-in-time audits and phase reports (UI audit, hosting audit, staging deployment, production preparation). Historical record; not kept up to date. |
| `superpowers/specs/` | Approved designs for larger features. |
| `superpowers/plans/` | Step-by-step implementation plans written from those designs. |
